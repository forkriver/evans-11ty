This intimate and inspiring portrait from veteran filmmaker Sean Menard (*The Carter Effect*) reveals the vulnerable human being behind the great Canadian icon. Drawing upon never-before-seen footage, Run Terry Run walks us through the arduous process and profound commitment that fostered Terry Fox’s magisterial Marathon of Hope.
